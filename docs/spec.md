# ひかいど MVP仕様

10/25問、必須診断4問、運営テンプレートのみ。公開時にスナップショットを保存し変更不可。下書き・管理秘密・結果秘密はlocalStorage。秘密はヘッダー送信しDBにはハッシュのみ保存。URL限定は認証付き非公開ではなく、秘密を失うと復旧不可。
公開設問APIは正解・タイプ・統計を返さない。選択後APIは指定問題の定性的リアクションのみ。結果詳細は秘密検証後。回答者一覧は新着32件カーソル。削除は外部キーCASCADE、統計は有効回答を都度集計。通報は名前をスナップショット保存。
D1 batchで複数書き込みを原子的に実施。クイズ内一意の冪等性キー。同じキーの再送には結果秘密の一致が必要。
診断は出題者の採用した全10/25問の回答を集計する。固定4問は最初の3軸の一致で各2点、4軸目は該当4タイプに1点。通常問題は回答に対応するタイプへ1点を加算し、タイプ間の違いを示さない好みはA/Bともカテゴリに対応する同じタイプへ加点する。バトル・ジョブ・PvPはバトル、物語は物語、装い・キャラ・撮影はおしゃれ、住居はハウジング、製作・採集・日課は職人、交流・音楽は交流、探索は探検、収集はコレクターを基本とし、複数タイプを比較する設問は選択肢に沿って加点先を変える。具体的な対応はtemplates.tsに定義する。同点は固定順。固定4問だけなら全16通りで各タイプ2回。娯楽目的であり、設問のカテゴリ構成によって診断が変わりうる。作成画面と公開処理は同じ集計関数を使用し、公開済みの診断は再計算しない。
D1固定窓レート制限、対象別通報制限、64KiB上限、Turnstile検証。本番未設定時は閉じる。ローカルだけ明示的バイパス。Slackは永続Outboxとリース、運営CLI再送。受理直後停止時の重複は完全には防止できない。
Catppuccin Latte/MacchiatoのUI。1問1画面、戻る、確認、リアクション。短いopacityトランジション、reduced-motion対応。公式画像不使用。
純粋関数と入力制約をVitestで先に固定し、D1統合E2EをPlaywrightで確認。本番作成・デプロイ・pushは承認後。

## 配色・共通ナビゲーション（追加指示）

Catppuccin Latte/Macchiatoを採用。アクセントはFlamingo（Latte: #dd7878、Macchiato: #f0c6c6）。ライト側のアクセント文字には濃い派生色（#a34545）、アクセント背景上の文字には#24273aを使い、可読性を確保する。colorant-picker / 4seasonsと同様、48pxヘッダー左にサービス名、右にメニューボタン、右端サイドドロワー、外部ホーム・プライバシーへのリンクを配置。日本語MVPのため言語切替なし。ドロワーはnative dialogでフォーカス制御。ヘッダーのBrandはLucide Heartと「ひかいど」。提供シンボルはfaviconとOGPに使用する。

## 画面表記（追加指示）
ユーザー向け画面では「管理」という語を使わず、「作ったクイズ」「回答を確認」「回答者を削除」「クイズを削除」と操作を明記する。運営の操作はCLIのみ。

並行する非表示操作と回答登録の間に隙間を作らないため、回答INSERT時に公開状態を確認するDBトリガーを置く。ボディ上限はContent-Lengthだけでなくストリームの実測でも強制する。

回答者一覧には有効な総回答数も表示する。他クイズに属する回答IDを削除対象に指定した場合は404で拒否する。E2Eは毎回一時D1を作成し、開発DBにデータ・レート制限を残さない。入力欄は下書き復元完了後に有効化し、SSR直後の入力が復元で上書きされるのを防ぐ。

## ブランド素材・OGP・画面文言の更新
提供されたブランド素材をOGPとfaviconに採用する。ヘッダーはLucide Heartと「ひかいど」のみ。操作・診断用のUIアイコンはLucideに統一。トップの英語コピーとレイド／ギャザクラ装飾は削除。キャッチコピーは「あのヒカセンのこと、どのくらいしってる？」。「自分のクイズ」は「あなたのクイズ」に統一。作成画面の共通診断4問の注記、固定問題の説明文、下書き自動保存の説明文は表示しないが、機能は維持する。

クイズOGPは公開中のクイズ名・問題数のみから生成。結果の共有は本人の結果秘密を検証後、別の公開用IDを発行し、出題者名と点数だけを公開する。共有URLに管理・結果秘密や回答明細を含めない。共有IDは回答に外部キーで紐付け、回答・クイズ削除で無効化。画像は1200×630 PNG、SNSメタデータはSSRで返し、削除・非表示を画像キャッシュから復活させない。提供テンプレートをSatoriとresvgで描画し、本番と同じWorkers実行環境でも確認する。

フッターに着想元としてリカイド（https://rikaido.me/）へのリンクを表示する。

## 出題テンプレート

テンプレートIDは一意とし、削除による欠番は詰めず、別の問題に再利用しない。通常問題にキャラ・装い・撮影・交流・バトル・日課・収集・探索・音楽の17問を追加する。アクセサリの問題は追加しない。公開済みクイズは保存済みのスナップショットを維持する。

診断問題と重複する通常問題（t009・t010）、t006と重複するt028は削除する。好みや行動の異なる軸を問う設問は残す。

トップの診断紹介は「8つのヒカセンタイプを診断。冒険の楽しみ方が見えてくるかも。」とし、共通4問や全回答についての前置きは表示しない。
